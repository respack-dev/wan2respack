# wan2respack

## NAME
wan2respack - Interface tool from Wannier90 to RESPACK for electronic structure calculations

## SYNOPSIS
```bash
python $PATH_to_Install/bin/wan2respack.py [OPTIONS] <config_file>
```

## DESCRIPTION
wan2respack is a connection program package that enables the use of Wannier functions generated by Quantum ESPRESSO and Wannier90 as input to RESPACK. This tool facilitates the calculation of dielectric functions and Coulomb interactions within the constrained/full random phase approximation (RPA).

## INSTALLATION

### Dependencies
1. Install Python package:
```bash
pip install tomli
```

2. Ensure you have the following software installed:
- [Quantum ESPRESSO](https://www.quantum-espresso.org)
- [Wannier90](http://www.wannier.org)
- [RESPACK](https://sites.google.com/view/kazuma7k6r)

### Build Instructions
```bash
git clone https://github.com/respack-dev/wan2respack.git
cd wan2respack
mkdir build
cd build
cmake ../ -DCONFIG=Type_of_Configure -DCMAKE_INSTALL_PREFIX=PATH_to_Install
make
make install
```

Where:
- `Type_of_Configure`: Use either `intel` or `gcc`
- `PATH_to_Install`: Your desired installation directory

## USAGE

### Basic Workflow
1. Perform DFT calculations for irreducible k-points using QE
2. Prepare Wannier90 input files
3. Generate Wannier functions using QE and Wannier90
4. Convert Wannier90 results to RESPACK format
5. Calculate Coulomb interactions using RESPACK

### Example Configuration
The tool uses a TOML configuration file (`conf.toml`):
```toml
[base]
QE_output_dir = "./work/Al.save"   # QE outdir prefix.save
seedname = "Al"                    # seedname for Wannier90

[pre.ref]
nscf = "Al.nscf.in"                # Reference file for QE nscf calculation
win = "Al.win.ref"                 # Reference file for Wannier90 input

[pre.output]
nscf = "Al.nscf_wannier.in"        # Output file for QE nscf calculation
win = "Al.win"                     # Output file for Wannier90 input
```

## EXAMPLES
See the `samples` directory for example calculations:
- Al.fcc.666
- La2CuO4.bct.666
- SrVO3.sc.666

### Step-by-Step Example: Al.fcc.666
Here's a detailed example using the Al.fcc.666 sample:

1. Navigate to the sample directory:
```bash
cd samples/Al.fcc.666/inputs
```

2. Perform DFT calculations using Quantum ESPRESSO:
```bash
$QE/bin/pw.x < Al.scf.in > Al.scf.out
$QE/bin/pw.x < Al.nscf.in > Al.nscf.out
```

3. Prepare Wannier90 input files:
```bash
python $PATH_to_Install/bin/wan2respack.py -pp conf.toml
```
This will:
- Save DFT wave functions in RESPACK format in `dir-wfn` directory
- Generate Wannier90 input files with appropriate k-point mesh

4. Generate Wannier functions:
```bash
$QE/bin/pw.x < Al.nscf_wannier.in > Al.nscf_wannier.out
$Wannier90/wannier90.x -pp Al
$QE/bin/pw2wannier90.x < Al.pw2wan.in > Al.pw2wan.out
$Wannier90/wannier90.x Al
```

5. Convert to RESPACK format:
```bash
python $PATH_to_Install/bin/wan2respack.py conf.toml
```
This creates Wannier functions and additional information in `dir-wan` directory.

6. Calculate Coulomb interactions:
```bash
$RESPACK/bin/calc_chiqw < respack.in > LOG.chiqw
$RESPACK/bin/calc_w3d < respack.in > LOG.W3d
$RESPACK/bin/calc_j3d < respack.in > LOG.J3d
```

### Configuration File Example
The `conf.toml` file for the Al.fcc.666 example:
```toml
[base]
QE_output_dir = "./work/Al.save"   # QE outdir prefix.save
seedname = "Al"                    # seedname for Wannier90

[pre.ref]
nscf = "Al.nscf.in"                # Reference file for QE nscf calculation
win = "Al.win.ref"                 # Reference file for Wannier90 input

[pre.output]
nscf = "Al.nscf_wannier.in"        # Output file for QE nscf calculation
win = "Al.win"                     # Output file for Wannier90 input
```
